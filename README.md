## Main projects

- **[NusaCommerce Data Platform](https://github.com/ibrahim119920/nusacommerce-data-platform)** —
  Data platform architecture with a Bronze → Silver → Gold flow, incremental PostgreSQL ingestion with checkpoints, and data-quality contracts. Built with Python, PostgreSQL, SQLAlchemy, and Docker Compose.
- **NYC Mobility Lakehouse** —
  Idempotent Bronze → Silver → Gold batch pipeline on Databricks for nine months (January–September 2024) of NYC TLC Yellow Taxi data, about 30 million trips. Built with PySpark, SQL, and Delta Lake.
- **[Highway Lane Occupancy & Hogging Detection](https://github.com/ibrahim119920/highway-lane-analytics)** —
  Computer-vision pipeline for highway CCTV that maps vehicles to calibrated lanes and flags lane hogging with YOLO11n and ByteTrack. Rules were tuned on 56 manually labelled vehicles, raising F1 from 0.54 to 0.93.
- **[Highway Lane Analytics — Data Pipeline & Dashboard](https://lane.syaifudin-fam.my.id/)** —
  FastAPI, Kafka, DuckDB, and Parquet platform that turns vision events into a Streamlit dashboard for lane usage, hogging signals, and data quality. Repository is private; a live replay dashboard is linked here.
